# Ansible (Post-Provision Configuration)

This folder contains Ansible playbooks used **after** Terraform/ParallelCluster provisioning to configure the head node and compute nodes.

## Use Cases

- Base OS hardening and user setup
- Spack bootstrap and module refresh
- Lmod modulepath configuration
- Exporters (Node/Slurm/DCGM) and Wazuh agent setup

## How It Fits

**Terraform** provisions infrastructure and ParallelCluster. **Ansible** handles post-provision configuration via:

- ParallelCluster `CustomActions` (post-install)
- A CI step that runs after `terraform apply`
- Manual run from a trusted admin host

## Example

```bash
ansible-playbook -i inventory/example.ini playbooks/site.yml
```

## Notes on Lmod

Lmod modulefiles are generated by Spack and exposed via `MODULEPATH`. This playbook only ensures the modulepath is set consistently (based on the official Lmod recommendations) and does not replace Spack/Lmod installation.
